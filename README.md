# BUSINESS-SALES-DASHBOARD-FROM-E-COMMERCE-DATA-Dashboard
Project Overview-
This project focuses on analyzing e-commerce sales data to uncover key business insights such as best-selling products, high-revenue categories, customer purchasing behavior, and monthly profit trends. Using Power BI, an interactive business intelligence dashboard was developed to help stakeholders make data-driven decisions.
The dashboard provides a comprehensive view of sales performance through dynamic visualizations, KPI cards, and category-wise breakdowns. It enables easy exploration of revenue trends, profit distribution, payment modes, and regional performance.
Objectives-
Analyze e-commerce transaction data to identify sales patterns,
Determine top-performing products and categories,
Track monthly profit and revenue trends,
Understand customer and regional sales distribution,
Support business decision-making through interactive visuals.
